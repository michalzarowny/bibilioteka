
# Biblioteka – aplikacja Android

## Opis projektu
Aplikacja umożliwia przeglądanie i wyszukiwanie książek.

## Technologie
- Java
- Android Studio
- XML
- RecyclerView

## Funkcjonalności
- Lista książek
- Wyszukiwanie po tytule i autorze
- Szczegóły książki
- Ulubione książki

## Struktura projektu
- Book.java – model książki
- BookData.java – dane książek
- BookAdapter.java – obsługa listy
- MainActivity.java – ekran główny
- BookDetailsActivity.java – szczegóły książki
